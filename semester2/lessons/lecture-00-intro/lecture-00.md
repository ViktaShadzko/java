## 📌 Слайд 6: Откуда вы пришли и куда идёте

Вы уже умеете писать **процедурный код** на Java:

```java
// ✅ Вы это уже знаете — процедурный стиль
public class PreviousSemester {

    public static double average(int[] grades) {
        int sum = 0;
        for (int grade : grades) {
            sum += grade;
        }
        return (double) sum / grades.length;
    }

    public static void main(String[] args) {
        int[] grades = {8, 9, 7, 10, 6};
        System.out.println("Средний балл: " + average(grades)); // 8.0
    }
}
```

Теперь мы научимся **думать объектами**:

```java
// 🚀 К этому мы придём — ООП стиль
public class Student {
    private String name;
    private int[] grades;

    public Student(String name, int[] grades) {
        this.name   = name;
        this.grades = grades;
    }

    public double getAverage() {
        int sum = 0;
        for (int g : grades) sum += g;
        return (double) sum / grades.length;
    }

    public String getSummary() {
        return name + " → средний балл: " + getAverage();
    }
}
```

## 📌 Слайд 8: Советы для успешного обучения

### 💡 Как учиться эффективно:

1. **Пишите код сами** — не копируйте, набирайте руками
2. **Экспериментируйте** — ломайте примеры и смотрите, что происходит
3. **Задавайте вопросы** — нет глупых вопросов на лекции
4. **Практикуйтесь каждый день** — даже 30 минут в день дают результат
5. **Используйте документацию** — [docs.oracle.com](https://docs.oracle.com/en/java/)
6. **Слушайтесь Многоуважаемую Анастасию Юрьевну** — она знает, как сделать вас лучшими программистами!
7. **Думать своей головой** — понимание важнее кода, сгенерированного ИИ

### ❌ Чего не делать:
- Не откладывать задания на последний момент
- Не копировать решения, не понимая их
- Не бояться ошибок — они часть обучения!
