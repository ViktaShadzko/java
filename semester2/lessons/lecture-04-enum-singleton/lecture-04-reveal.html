1. Enum — типобезопасные константы

Замена int-константам

Зачем Enum? Проблема int-констант

// ❌ До Enum — int константы
public class OrderStatus {
    public static final int PENDING   = 0;
    public static final int CONFIRMED = 1;
    public static final int SHIPPED   = 2;
}
// Можно передать любое число!
processOrder(42); // ❌ но компилируется!
// ✅ С Enum — типобезопасность
public enum OrderStatus {
    PENDING, CONFIRMED, SHIPPED, DELIVERED
}

// Компилятор знает допустимые значения
void processOrder(OrderStatus status) { }
processOrder(OrderStatus.SHIPPED); // ✅
// processOrder(42); // ❌ compile error!
OrderStatus s = OrderStatus.SHIPPED;

System.out.println(s);           // SHIPPED
System.out.println(s.name());    // SHIPPED
System.out.println(s.ordinal()); // 2

// Сравнение
if (s == OrderStatus.SHIPPED) { }

// switch
switch (s) {
    case PENDING   -> System.out.println("Ожидает");
    case CONFIRMED -> System.out.println("Подтверждён");
    case SHIPPED   -> System.out.println("Отправлен");
    case DELIVERED -> System.out.println("Доставлен");
}

// Все значения
for (OrderStatus status : OrderStatus.values()) {
    System.out.println(status.ordinal()
                       + ": " + status);
}

// Из строки
OrderStatus shipped =
    OrderStatus.valueOf("SHIPPED");

Enum с полями и методами

public enum Planet {
    MERCURY(3.303e+23, 2.4397e6),
    VENUS  (4.869e+24, 6.0518e6),
    EARTH  (5.976e+24, 6.37814e6),
    MARS   (6.421e+23, 3.3972e6);

    private final double mass;   // кг
    private final double radius; // м
    private static final double G
        = 6.67300E-11;

    // Конструктор enum — всегда private!
    Planet(double mass, double radius) {
        this.mass   = mass;
        this.radius = radius;
    }

    public double surfaceGravity() {
        return G * mass / (radius * radius);
    }
    public double surfaceWeight(
                        double m) {
        return m * surfaceGravity();
    }
}
// Абстрактный метод в Enum
public enum Operation {
    ADD("+") {
        @Override
        public double apply(double x,
                            double y) {
            return x + y;
        }
    },
    SUBTRACT("-") {
        @Override
        public double apply(double x,
                            double y) {
            return x - y;
        }
    },
    MULTIPLY("*") {
        @Override
        public double apply(double x,
                            double y) {
            return x * y;
        }
    };

    private final String symbol;
    Operation(String s) { symbol = s; }

    public abstract double apply(
                double x, double y);

    @Override public String toString()
        { return symbol; }
}

for (Operation op : Operation.values()) {
    System.out.printf("10 %s 3 = %.2f%n",
        op, op.apply(10, 3));
}

2. Паттерн Singleton

Один объект на всю программу

Singleton — реализации

Вариант 1: Lazy (небезопасный):

public class ConfigSingleton {
    private static ConfigSingleton instance;

    private ConfigSingleton() {
        // приватный конструктор
    }
    public static ConfigSingleton
                  getInstance() {
        if (instance == null) { // ⚠️ не потокобезопасно!
            instance =
              new ConfigSingleton();
        }
        return instance;
    }
}

Вариант 2: Double-Checked Locking:

public class ThreadSafeConfig {
    private static volatile
        ThreadSafeConfig instance;

    public static ThreadSafeConfig
                  getInstance() {
        if (instance == null) {
            synchronized (
              ThreadSafeConfig.class) {
                if (instance == null)
                    instance =
                      new ThreadSafeConfig();
            }
        }
        return instance;
    }
}

✅ Лучший способ — Enum Singleton:

// Рекомендует Joshua Bloch
// "Effective Java", Item 3
public enum DatabaseConnection {
    INSTANCE; // единственный объект

    private final String url =
      "jdbc:postgresql://localhost/app";
    private int connectionCount = 0;

    public void connect() {
        connectionCount++;
        System.out.println(
          "Подключение #" +
          connectionCount);
    }
    public String getUrl() { return url; }
}

// Использование
DatabaseConnection db1 =
    DatabaseConnection.INSTANCE;
DatabaseConnection db2 =
    DatabaseConnection.INSTANCE;

System.out.println(db1 == db2); // true!
db1.connect(); // Подключение #1
db2.connect(); // Подключение #2
System.out.println(
    db1.connectionCount); // 2!

📌 Итоги

  • Enum — типобезопасные константы. Нельзя создать через new.
  • Enum может иметь поля, методы, конструктор.
  • Абстрактные методы — каждая константа обязана реализовать.
  • EnumSet/EnumMap — быстрые коллекции для Enum.
  • Singleton — один объект на JVM.
  • Лучший Singleton — через Enum (Bloch).
  • Не злоупотребляй Singleton — затрудняет тестирование.
