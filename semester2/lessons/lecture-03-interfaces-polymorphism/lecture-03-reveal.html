1. Абстрактные классы

Шаблон с неполной реализацией

Abstract class — шаблон для наследников

public abstract class Shape {
    protected String color;
    protected String name;

    public Shape(String color, String name) {
        this.color = color;
        this.name  = name;
    }

    // Абстрактный — ОБЯЗАН быть реализован
    public abstract double area();
    public abstract double perimeter();

    // Обычный — общий для всех
    public void printInfo() {
        System.out.printf(
          "%s [%s] — S=%.2f, P=%.2f%n",
          name, color, area(), perimeter());
    }
}

public class Circle extends Shape {
    private double radius;
    public Circle(String color, double r) {
        super(color, "Круг");
        this.radius = r;
    }
    @Override
    public double area() {
        return Math.PI * radius * radius;
    }
    @Override
    public double perimeter() {
        return 2 * Math.PI * radius;
    }
}
public class Rectangle extends Shape {
    private double w, h;
    public Rectangle(String c,
                     double w, double h){
        super(c, "Прямоугольник");
        this.w = w; this.h = h;
    }
    @Override public double area()
        { return w * h; }
    @Override public double perimeter()
        { return 2*(w+h); }
}

// Полиморфизм
Shape[] shapes = {
    new Circle("красный", 5),
    new Rectangle("синий", 4, 6)
};
for (Shape s : shapes) s.printInfo();
// Круг [красный] — S=78.54, P=31.42
// Прямоугольник [синий] — S=24.00
Нельзя создать abstract

new Shape("red","x") → ❌ compile error!

2. Интерфейсы

Контракт — ЧТО умеет, но не КАК

Interface — контракт без реализации

// Интерфейс — сигнатуры методов
public interface Drawable {
    void draw();
    void resize(double factor);
}

public interface Saveable {
    void save(String filename);
    void load(String filename);
}

// Класс реализует НЕСКОЛЬКО интерфейсов
public class Canvas
        implements Drawable, Saveable {

    private String content;

    @Override public void draw() {
        System.out.println("Рисую: "
          + content);
    }
    @Override public void resize(double f){
        System.out.println("Масштаб: "+f);
    }
    @Override public void save(String f) {
        System.out.println("Сохранено: "+f);
    }
    @Override public void load(String f) {
        System.out.println("Загружено: "+f);
    }
}

3. Перегрузка vs Переопределение

Overloading vs Overriding

Overloading (перегрузка) — compile time

public class Calculator {
    // По типу параметра
    public int add(int a, int b) {
        return a + b;
    }
    public double add(double a, double b) {
        return a + b;
    }
    public String add(String a, String b) {
        return a + b;
    }
    // По количеству параметров
    public int add(int a, int b, int c) {
        return a + b + c;
    }
}

Calculator c = new Calculator();
c.add(1, 2);         // int + int
c.add(1.5, 2.5);     // double + double
c.add("Hi", " World"); // String+String
// ── Overriding (переопределение) ─────
// Runtime — динамический dispatch!
public class Logger {
    public void log(String msg) {
        System.out.println("[LOG] "+msg);
    }
}
public class FileLogger extends Logger {
    private String file;
    public FileLogger(String file) {
        this.file = file;
    }
    @Override public void log(String msg) {
        System.out.println(
          "[FILE:"+file+"] "+msg);
    }
}

Logger l1 = new Logger();
Logger l2 = new FileLogger("app.log");

l1.log("Старт"); // [LOG] Старт
l2.log("Старт"); // [FILE:app.log] Старт
// ← вызывается по РЕАЛЬНОМУ типу!

4. Default-методы и функциональные интерфейсы

Java 8+

Default-методы и @FunctionalInterface

public interface Notification {
    // Абстрактный — обязателен
    void send(String message);

    // Default — реализация по умолчанию
    default void sendWithTimestamp(
                         String message) {
        send("[" +
          LocalDateTime.now() + "] "
          + message);
    }

    // Static — утилитный метод
    static boolean isValid(String msg) {
        return msg != null && !msg.isBlank();
    }
}

class EmailNotification
        implements Notification {
    private String email;
    EmailNotification(String e)
        { this.email = e; }

    @Override
    public void send(String msg) {
        System.out.println(
          "Email→"+email+": "+msg);
    }
    // sendWithTimestamp — дефолтный
}
// @FunctionalInterface
// — ровно ОДИН абстрактный метод
@FunctionalInterface
public interface Validator<T> {
    boolean validate(T value);

    default Validator<T> and(
               Validator<T> other) {
        return v -> this.validate(v)
                 && other.validate(v);
    }
}

// Используем с лямбдами!
Validator<String> notEmpty =
    s -> !s.isBlank();
Validator<String> shortEnough =
    s -> s.length() <= 20;

Validator<String> usernameOk =
    notEmpty.and(shortEnough);

System.out.println(
    usernameOk.validate("johndoe")); // true
System.out.println(
    usernameOk.validate(""));        // false

📌 Итоги

  • Abstract class — шаблон, нельзя создать объект
  • Interface — контракт, множественная реализация
  • Полиморфизм — реальный тип определяет поведение
  • Overloading — разные параметры, compile time
  • Overriding — наследник заменяет метод, runtime
  • default методы — реализация в интерфейсе (Java 8+)
  • @FunctionalInterface — один метод → лямбда
