Зачем дженерики? Проблема кастов

// ❌ Без дженериков — Object
List list = new ArrayList();
list.add("Привет");
list.add(42);       // можно что угодно!
String s = (String) list.get(1);
// ❌ ClassCastException в рантайме!
// ✅ С дженериками
List<String> list = new ArrayList<>();
list.add("Привет");
list.add("Мир");
// list.add(42); // ❌ compile error!
String s = list.get(0); // без каста!
// Параметризованный класс
public class Box<T> {
    private T value;
    public Box(T value) { this.value = value; }
    public T getValue()  { return value; }
    public boolean isEmpty() { return value == null; }
}
Box<String>  sb = new Box<>("Привет");
Box<Integer> ib = new Box<>(42);
System.out.println(sb.getValue()); // Привет
// Несколько параметров типа
public class Pair<K, V> {
    private final K key;
    private final V value;
    public Pair(K k, V v) { key=k; value=v; }
    public K getKey()   { return key;   }
    public V getValue() { return value; }
}
Pair<String, Integer> age =
    new Pair<>("Иван", 25);
System.out.println(age.getKey());   // Иван
System.out.println(age.getValue()); // 25

Bounds — ограничения типов

// extends — T должен быть Number
public class Statistics<T extends Number> {
    private List<T> data;
    public Statistics(List<T> data) {
        this.data = data;
    }
    public double sum() {
        return data.stream()
            .mapToDouble(Number::doubleValue)
            .sum(); // Number.doubleValue() доступен!
    }
    public double average() {
        return data.isEmpty() ? 0
               : sum() / data.size();
    }
}
Statistics<Integer> si =
    new Statistics<>(List.of(1,2,3,4,5));
System.out.println(si.sum());     // 15.0
System.out.println(si.average()); // 3.0
// Statistics<String> ss = ...  // ❌
// PECS — Producer Extends, Consumer Super
// Читаешь из коллекции → extends
public static double sumNumbers(
        List<? extends Number> list) {
    return list.stream()
               .mapToDouble(Number::doubleValue)
               .sum();
}
sumNumbers(List.of(1, 2, 3));   // Integer ✅
sumNumbers(List.of(1.5, 2.5)); // Double ✅
// Пишешь в коллекцию → super
public static void addIntegers(
        List<? super Integer> list) {
    list.add(1); list.add(2); list.add(3);
}
List<Number> nums = new ArrayList<>();
addIntegers(nums); // ✅
Стирание типов

В байткоде параметров типов нет. List<String> и List<Integer> — один List. Нельзя: new T(), new T[], instanceof T.

📌 Итоги

  • Дженерики — типобезопасность без кастов
  • <T extends Foo> — ограничение сверху
  • PECS: Producer Extends, Consumer Super
  • Стирание типов — параметры существуют только при компиляции
  • Нельзя: new T(), instanceof T
