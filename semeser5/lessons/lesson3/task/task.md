# Lab 1. 1

## Task
1. Разработать небольшое приложение с одной бизнес сущьность (курс валют или другая на ваш выбор)
    за что то кроме курсов валют +0.5 балла
    Реализовать эндпоинты:
        - GET /rates - list all rates
        - GET /rates/{currency} - get rate for specific currency
        - POST /rates - add new currency rate
        - PUT /rates/{currency} - update existing currency rate
        - DELETE /rates/{currency} - delete currency rate
2. Реализовать слои контроллер, сервис, репозиторий
3. использовать для хранения даных List или Map в репозитории
4. передайте параметр через request body при создании и обновлении курса валюты
5. передайте параметр через path variable при получении и удалении курса валюты
6. передайте параметры через query param при получении списка курсов валют
7. передайте параметры через header в любом из запросов
8. добавт openapi спецификацию для ваших контролеров(можете использовать генератор)

 ## Дополнитьельные задания
1. обернуть ответ в объект response с дата и информацией о количестве элементов
2. обернуть в респонс ентити все методы контролера
