# Пройденные темы

> Что студенты уже изучили в этом семестре

## 📚 Основные темы

1. **HTTP Client** - работа с HTTP запросами
2. **JSON** - формат обмена данными
3. **REST API** - основы RESTful архитектуры
4. **Servlet API** - серверные Java-компоненты
5. **JSP** (JavaServer Pages) - динамические веб-страницы
6. **JDBC** - работа с базами данных
7. **HTML/CSS** - основы веб-разметки и стилизации
8. **Postman** - тестирование API
9. **JWT** - основы токен-аутентификации
