# Темы для дальнейшего изучения

> План обучения на следующие занятия

## 🌱 Spring Ecosystem

1. **Spring Framework** - основы фреймворка
2. **Spring Boot** - быстрая разработка приложений
3. **Spring Data JPA / Hibernate** - работа с БД через ORM
4. **Spring MVC / Controller** - веб-контроллеры и обработка запросов
5. **Error Handling** - обработка ошибок и исключений
6. **Spring Security** - аутентификация и авторизация

## 🛠️ Инструменты разработки

7. **Maven / Gradle** - системы сборки проектов
8. **Swagger / OpenAPI** - документирование API

## ✅ Качество кода

9. **Тестирование** - JUnit, Mockito
10. **Логирование** - SLF4J, Logback

## 🚀 Продвинутые темы

11. **Работа с кэшем** - Ehcache, Redis
12. **CI/CD** - основы непрерывной интеграции и развертывания
